## Проверенные правила

Сопоставлены `team_racing.py`, `team_racing_service.py`, `team_racing_exchange.py`, HTTP-маршруты auth и frontend client. Сервер остаётся источником окончательного решения.

| Правило | Поведение |
| --- | --- |
| Команда и машина | Одна активная заявка и одна машина на команду; все пилоты должны состоять в ней |
| Состав | От 1 до установленного максимума; соло разрешено; создатель включён при первичной записи |
| Капитан | Выбирается из экипажа; номер берётся из его профиля; он входит и нажимает Drive первым |
| Подтверждение | При отправке подтверждается участие создателя, если он в составе; остальные подтверждают сами после Steam-входа |
| Изменение | Машина, капитан или состав требуют повторного подтверждения остальных; неизменённая заявка не отправляется повторно |
| Закрытие | Запись, изменения, отзыв и подтверждения заканчиваются ровно за час до открытия сервера |
| Неполное подтверждение | Вся команда исключается; состав самопроизвольно не сокращается |
| Очередь | CSRF, expected_version и idempotency_key; личность отправителя устанавливает сервер |

В действующем командном backend номер капитана ограничен диапазоном **1–998**, хотя общий кабинет допускает запрос номера 999. Интерфейс командной записи теперь объясняет этот существующий предел; серверная политика не менялась.

## Что исправлено

1. Форма разбита на понятные шаги: команда → машина/экипаж → капитан/проверка. Есть краткая сводка перед отправкой, явный срок и статус регистрации.
2. Выбор команды, машины, капитана и экипажа сохраняется при обычном обновлении. Новая серверная версия заменяет конфликтующий черновик после обновления.
3. До отправки объясняются отсутствие номера, отсутствие допуска, неверный состав/машина, дубли пилотов, конфликт номера, заполненная сетка и лимит подключений. Нельзя выбрать больше разрешённого числа пилотов.
4. Потеря ответа и истечение ожидания не разблокируют повторную отправку. Незавершённая операция сохраняется в sessionStorage этой вкладки; после перезагрузки проверяется тот же command ID или повторяется запрос с прежним idempotency_key. Если хранилище недоступно, сохраняется блокировка в памяти текущей страницы.
5. Явный HTTP-отказ освобождает форму для исправления. Сбой получения свежего состояния блокирует изменения до успешного обновления.
6. Отзыв всей команды требует отдельного подтверждения. Создатель может скопировать ссылку для экипажа; при отказе Clipboard API появляется выделяемое поле.
7. Из карточек и модалок V2 передаются occurrence_id и язык через общий `teamRaceUrl`. Исправлены устаревший RU-маршрут и потеря языка. Командные карточки показывают формат экипажа вместо счётчика одиночных голосов.
8. Обновлён сохраняемый native HTML-шаблон `v1-source/html/hourly/team/index.html`: root-сборка раньше подставляла старую оболочку поверх нового JS. Добавлена регрессионная проверка равенства текущей страницы и шаблона.

Новый интерфейс использует существующий логотип, тёмные панели, красные акценты и компактные формы V2. На телефоне форма и список идут последовательно; поля, подписи и длинные названия проверены до 320 px. ASG Lab и другие отложенные функции не изменялись.
