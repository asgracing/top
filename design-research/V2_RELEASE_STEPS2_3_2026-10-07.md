# V2: адреса, переходы и SEO — шаги 2–3

07.10.2026. Статус: выполнено локально; кандидат подготовлен для просмотра. Коммита, push, переключения production и изменений Cloudflare/VPS нет. Backend не изменён.

## Что подготовлено

- V2 RU в `/`, V2 EN в `/en/`: 29 экранов, 58 HTML-страниц.
- Старый интерфейс в `/old/` и `/old/en/`: 25 маршрутов, 50 HTML-страниц. Сохранены прежняя разметка, действующие контроллеры и данные.
- Единый `v2/site-routing.js` используется навигацией V2, локализацией native-контроллеров, меню профиля и переключателем версий. В старом интерфейсе ограниченный MutationObserver обрабатывает только добавленные ссылки, без опроса и наблюдения за стилями.
- Переключение языка и версии сохраняет `id`, `slug`, фильтры, страницу списка, UTM и якорь. Для результата гонки V2 `id` преобразуется в `race_id` старого архива, который открывает модалку независимо от доступности списка архива. Для статьи используется native `slug`.
- RU в корне имеет приоритет над сохранённым EN, языком браузера и `?lang=en`. Переключение языка private-страниц старого сайта меняет URL, включая native-кнопки, которые раньше только перезагружали страницу.
- Возврат после входа/повторной авторизации в модерации и Portal Ops теперь использует текущие путь и query вместо жёстких `/moderation/` и `/portal-ops/`. Существующий валидатор локальных return paths в исходниках auth допускает новые префиксы; реальный Steam OAuth не выполнялся.
- Кнопка нового интерфейса обозначена «Старый сайт» / «Old site», старого — «Сайт v2» / «Site v2».
- Адреса публичных данных, auth и votes API не переписываются. ASG Lab и командная регистрация остаются на native entry points с прежними проверками доступа; не включены в редизайн.

## SEO и удаление третьей версии из релиза

Отдельный `build:root-release` добавляет self canonical и парные `ru-RU`, `en`, `x-default` (RU), корректные описания и Open Graph/Twitter metadata для каждого экрана. Sitemap содержит 34 адреса индексируемых обзорных/информационных страниц. Private-страницы, профили/результаты/другие сущности с query, `/old/` и 404 остаются `noindex,follow`; старый интерфейс и альтернативные URL отсутствуют в sitemap.

`robots.txt` указывает новый sitemap. Старые страницы не закрыты от обхода robots.txt, чтобы поисковик мог прочитать их `noindex`. Это техническая политика кандидата, а не изменение production.

Публичный каталог `preview/`, его runtime, компоненты и snapshots исключены из релизного артефакта. Сохранён только независимый исторический список 43 URL в `v1-source/retired-preview-routes.json` для карты перенаправлений. Исходный Preview пока сохранён в checkout и обычной прежней сборке: фактическое удаление из опубликованного сайта должно произойти в составе согласованного переключения. Native preview модалки пилота и Portal Ops event preview сохранены — это действующие функции, не третья версия сайта.

## Совместимость адресов

Подготовлено 287 точных сопоставлений: RU aliases, `/v2/{ru,en}/`, `/preview/`, `index.ru.html`, events и hourly legal aliases. Нет префиксного правила `/v2/*`, которое могло бы перехватить JS/CSS/картинки. Current root/EN/old и API не перенаправляются; тесты проверяют отсутствие циклов и цепочек между статическими целями.

Файлы находятся вне публичного артефакта:

- `C:/Python/asgracing/tmp/root-redirects.json` — карта, статус `not-applied`.
- `C:/Python/asgracing/tmp/root-redirects-cloudflare.csv` — CSV без заголовка, 301, query сохранён, subdomain/subpath/suffix matching выключены. Формат сверён с [официальной документацией Cloudflare](https://developers.cloudflare.com/rules/url-forwarding/bulk-redirects/reference/csv-file-format/).

На совместимых RU/V2/alias адресах артефакт содержит HTML/JS fallback, сохраняющий query/hash. Это **HTTP 200 + клиентский переход**, а не настоящий 301. Preview HTML не включён: его существующие входные адреса требуют активации карты HTTP-редиректов до удаления старого сайта. Реальные правила Cloudflare ещё не применены; DNS proxy/доступ к зоне и лимиты правил не проверены в этом шаге.

Старые `/news/?slug=…` и `/races/?race_id=…` распознаются новым клиентом и открывают соответствующие статью/результат с сохранением сущности. Для строго одного HTTP-перехода на таких query-зависимых адресах нужны отдельные условные edge-правила: Bulk CSV сопоставляет пути и сохраняет query, но не переименовывает параметры.

Перед publication остаётся подтвердить, был ли отдельный Google Analytics подключён вне frontend, и при необходимости получить существующий ID. Поступление событий и состояние sitemap в кабинетах Метрики/Search Console не проверялись. Юридические тексты и существующее предупреждение о преимущественном RU тексте английских документов не менялись.

Это согласуемый локальный snapshot, не committed/deployed release. `.previous` — откат локальной сборки, не production backup.
