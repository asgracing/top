# Главная V2 — локальная интеграция

06.10.2026. Реализована и опубликована только главная RU/EN: `https://asgracing.ru/v2/ru/`, EN — `https://asgracing.ru/v2/en/`. Релиз `e67315faac352620b74762082b821c8172dae725`, предыдущий `5c8741930df424eb89ed67e2a6c06479c2d3eb84`. GitHub CI и Pages завершились успешно; HTML и ключевые JS/CSS сверены по SHA-256 с коммитом. Backend, VPS и игровые серверы не изменялись. Остальные страницы открываются в действующей версии сайта.

## Входы и просмотр

- `http://127.0.0.1:8840/v2/` — русский при первом открытии, затем сохранённый RU/EN.
- `/v2/ru/` и `/v2/en/` — прямые входы, независимо от сохранённого выбора.
- Переключатель в шапке обеих главных. Язык, query и известные якоря сохраняются.
- `/` и `/ru/` остаются прежними входами. `/preview/` сохраняет самостоятельный прототип.

Статический просмотр из корня `top`: `python -m http.server 8840 --bind 127.0.0.1`. Просмотр работает с действующими публичными источниками; нажимать участие при ручной проверке означает настоящее действие API. Автоматические проверки ниже перехватывают запись.

## Реализация

| Файл | Назначение |
| --- | --- |
| `v2/home.js`, `v2/home.css`, `v2/bridge.js` | Новое представление, адаптивность, состояния и действия |
| `scripts/build-v2.mjs`, `scripts/v2-runtime-facade.txt` | Воспроизводимая сборка поверх канонических контроллеров `app.js` |
| `v2/{ru,en}/index.html`, `v2/index.html` | Статические входы и исходное SEO-содержание |
| `v2/runtime/home.js`, `v2/runtime-source.json` | Сгенерированный контроллер и SHA-256 исходного `app.js`; не редактировать вручную |
| `v2/styles/design.css`, `v2/copy.js`, `v2/assets/` | Собранный дизайн R24, редакционные RU/EN-тексты, SVG и QR |
| `src/features/home-version-switch.js`, `src/entrypoints/home.js` | Переход с главной V1 в V2 |
| `package.json`, `scripts/build-dist.mjs` | Проверка, генерация и включение V2 в обычную сборку сайта |

Генератор использует зафиксированные HTML, CSS и редакционные тексты R24 в `v2-source/`; брендовые изображения отслеживаются в `v2/assets/`. Сборка не зависит от исследовательских снимков. Демонстрационные наборы профилей, расписание и сохранённые участия не включаются в runtime V2. Отдельные сокращённые публичные фикстуры для browser-проверок лежат в `tests/fixtures/v2-home/`.

Нативные контроллеры сохраняют свои DOM-узлы в скрытом источнике; диалоги вынесены из него в видимую часть. V2 рендерит данные отдельно, а действия пилота, истории рейтингов, онлайн, событие и участие использует из действующего приложения. Генератор проверяет наличие точек подключения и прекращает сборку при несовместимом изменении исходного контроллера. Видеофон V1 не загружается.

## Данные и действия

| Блок | Действующий источник / действие |
| --- | --- |
| Статистика, пилот дня, последний победитель | `top-data/v2/manifest.json`, `home.json`, публичные профили и детали гонки |
| Рейтинг, лучшие круги, SR | Действующие страницы/чанки таблиц; 10 строк, фильтр трассы, поиск и сортировка |
| Клубы и команды | `public-cache-clubs-teams/current.json`, согласованный snapshot, детали участников и три опубликованных контекста рейтинга |
| Ближайшая гонка | `hourly-data/announcement.json`, `schedule.json`, родные правила события и модалка |
| Участие и отмена | Действующий токен-клиент Hourly, перенос прежнего браузерного voter ID, сохранение штатных ограничений регистрации |
| Серверы и пилоты | `top-data/server_status.json`, девять серверов, отметка устаревания, опубликованные ID при наличии |
| Поддержка | `donations-api/recent`, действующая цель, последние пять донатов |
| Авторизация и уведомления | Общий auth-header, реальные права сессии, родной компонент новостей |

Недостающие значения показываются прочерком. Общие победы/подиумы/гонки берутся из сводки профиля, а изменения очков/ELO/SR — из результата последней гонки. Любимая машина не подменяется машиной лучшего круга. Неподтверждённые ID и права не угадываются.

## Аналитика и SEO

- Тот же `legal.js`, ключ `asgPrivacyConsent`, редакция согласия и Яндекс Метрика `107697834`. Проверено отсутствие загрузки до согласия и один init после него.
- Оба подтверждения Яндекса и Google Search Console перенесены без изменения. Отдельного GA/GTM в проверенных исходниках нет.
- Старые canonical, hreflang, sitemap и robots.txt не менялись. V2 использует `noindex,follow` и пока не имеет отдельного canonical/hreflang. URL организации и сайта в JSON-LD сохранены, Open Graph URL соответствует конкретному входу V2.
- SEO-текст есть в исходном HTML RU/EN и видимом нижнем блоке. Аналитические кабинеты и поступление событий в production не проверялись.

## Проверки и ограничения

- `npm.cmd run ci`: проверки сайта/SEO/бюджетов, 336 unit-тестов в отдельном релизном scope, сборка, контроль файлов и ссылок, smoke 35 маршрутов/ресурсов проходят. Предыдущая проверка смешанного дерева включала 342 теста; связанные с другими задачами изменения не вошли в релиз.
- `npm.cmd run check:v2`: совпадение контроллера по SHA-256, синтаксис, языки, идентификаторы аналитики и поисковиков, изоляция индексации проходят.
- `node tests/deployment/check-v2-home.mjs`: RU/EN, 1920×936, 1280×720, 390×844 и 320×844; отсутствие JS-ошибок, дублей ID и горизонтального переполнения; рейтинги, модалки, запись/отмена, ошибка записи, авторизация/своя строка, права меню, подсказки, стрим, согласие и сохранение панелей. Дополнительно проверено отсутствие preview-строк в `home.json`, как в текущем публичном экспорте. Реальные записи и аналитические запросы перехвачены.
- HTTP GET через `curl.exe` подтвердил доступность актуальных manifest/home/announcement, таблиц и последней гонки; их поля сопоставлены с новым представлением.
- Прямая проверка из локального headless Chrome ограничена `ERR_CONNECTION_RESET` на HTTPS к публичным данным. Отдельный необязательный `check-v2-live-readonly.mjs` блокирует все мутации, авторизацию, аналитику и голосование; его прямой сетевой smoke в этой среде не прошёл. Это не production-проверка. PowerShell/.NET также не получил данные; самостоятельный curl получил HTTP 200.
