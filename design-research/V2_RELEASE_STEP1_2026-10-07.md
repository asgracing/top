- Репозиторий проверен: `top`, `main`, `asgracing/top.git`. После fetch актуальный `origin/main` совпал с HEAD `211c939cb708d3d010ac4ecd7a5ab961ec011760`. Это базовая production revision; новые изменения остаются в смешанном незакоммиченном рабочем дереве.

- Локализатор экспортирует `renderLocalizedPages()`, читает сохранённые шаблоны и поддерживаемые словари и отдаёт HTML в памяти. V2 использует эти входы для главной, native модалок, legal/editorial content и форм управления. Публичные root/ru HTML больше не являются его шаблонами.
- `v2/page-registry.js` объединяет 29 экранов: route/screen, RU/EN названия и описания, доступ, query-параметры, будущие target URL и существующий V1 эквивалент. Генератор и `v2/routes.js` используют один реестр. Пока действуют `/v2/{ru,en}/`.
- Canonical `app.js` и runtime V2 согласованы. Сохранены локальные исправления московских дат, сортировки, банов/страйков и профиля, текущая пагинация, события и ограничение фоновой нагрузки. Восстановлен существующий общий Hourly token client вместо старого `voter_id`-запроса. Из V2 facade удалён второй transport/client: действия вызывают canonical функции.
- Runtime пересобран штатным генератором, версия `20261007v2release1`. Исходный hash: `6f0e5887d069d278a768c06b7263610c2d2e8e0ed3758d890646645323f7853e`; output hash: `71988a2c958785d104fa60d54e9382a307470fefa27ee2f140919c7df3bd125e`. Проверяются также facade и inventory входов. Hash не подменялся вручную.
- `ASG_V2_PRESENTATION_ONLY=1` теперь явно запрещён. Повторная сборка не переписывает неизменённые файлы; изменённый файл заменяется через временный файл, чтобы локальный сервер не отдал наполовину записанный HTML/JS.
- Статические ссылки генерируемой V2 приведены к её языковым маршрутам. Исправлена отсутствующая `/championships/` до запуска JS; переключатель на V1 остаётся отдельной ссылкой.
