# ASG Racing: альтернативная версия

Текущая версия остаётся на `/` и `/ru/`. Альтернативная — на `/preview/` и `/preview/ru/`. Переход только по прямой ссылке. Ни редиректа посетителей, ни выбора версии в cookie, ни ссылки из основной навигации нет. Кнопка возврата сохраняет страницу, параметры и якорь.

Это интерфейс к существующей системе, а не отдельная тестовая база: аккаунты, участие, голосование, номера, команды, операторские действия используют прежние API. Выполненные действия имеют реальные последствия для общего аккаунта. Авторизация Steam сохраняет `return_path=/preview/...`; CSRF, права оператора и существующий закрытый доступ ASG Lab остаются на сервере. `/preview/asg-lab/` открывает тот же защищённый серверный просмотр, его интерфейс не клонируется и доступ не расширяется. Отложенные функции подписки не реализованы.

## Источники и обновление

- `app.js`, `design.css`, `routes.js` в этой папке — новая компоновка, оформление и карта маршрутов.
- `../scripts/build-preview.mjs` создаёт HTML всех 43 адресов и изолированный снимок существующих обработчиков в `runtime/` только по явной команде `npm run build:preview`. HTML и `runtime/` не редактировать вручную: менять генератор или оформление и пересоздавать.
- `source-manifest.json` фиксирует хеш каждого исходника и результата. Основа снимка — текущее локальное рабочее дерево, включая ранее существовавшие локальные доработки; это не заявление о соответствии опубликованному `main`.
- Обычная сборка `npm run build` и CI проверяют закреплённый снимок и включают его в dist, не пересоздавая из исходников основной версии. Проверка `node scripts/check-preview.mjs --source` дополнительно сравнивает снимок с локальными исходниками перед его обновлением. Хеши нормализованы к LF для одинакового результата на Windows/Linux.
- При следующем выпуске обновлять query-версию `design.css` и `app.js` в генераторе и версии изменившихся runtime-модулей: отдельная папка изолирует дизайн, но не отменяет кеширование браузера/CDN.
- Изображения и публичные JSON принадлежат основному сайту, копии медиа не создаются. API URL не получают префикс `/preview`. Языковые настройки предпросмотра используют отдельные ключи, аккаунт и состояние участия общие.
- HTML содержит `noindex,nofollow,noarchive`, отсутствует в основном sitemap. Отдельный robots Disallow не добавляется: он помешал бы роботу увидеть noindex. Прямая ссылка доступна всем; это не закрытая бета.

```powershell
node scripts/build-preview.mjs
node scripts/check-preview.mjs --source
npm.cmd run verify
npm.cmd run build
npm.cmd run verify:dist
python -m http.server 8766 --bind 127.0.0.1
```

Локальный просмотр: `http://127.0.0.1:8766/preview/ru/`. Для реального входа нужен опубликованный адрес на `asgracing.ru`: Steam callback возвращает на настроенный сервером домен. Локальные проверки действий проводятся через фикстуры без production POST.

## Публикация и переключение

Публикация отдельно требует указания пользователя. Файлы preview включены в allowlist существующей сборки `build-dist.mjs`; текущие HTML/CSS/JS и основной sitemap не меняются этой работой. В смешанном рабочем дереве нельзя публиковать весь накопленный diff: сначала проверить и выбрать только согласованные изменения. Обновление снимка — отдельный явный шаг; проверенный снимок при публикации не пересоздавать.

После публикации открыть `/preview/ru/`, проверить доставку ресурсов, вход с возвратом в preview, участие и кабинет реальным разрешённым аккаунтом. Пока эти проверки не выполнены, не объявлять production-действия проверенными. Доступная сейчас автоматическая проверка использует публичные GET и имитацию ответов защищённых API.

Для постепенного запуска сначала дать прямую ссылку команде, затем при отдельном решении добавить небольшую ссылку «Попробовать новую версию» на основной сайт. Делать preview основной версией можно отдельным релизом после приёмки всех сценариев. До этого привычные URL, поиск и обычные посетители остаются на текущей версии. Откат альтернативы — убрать только `preview` из опубликованного пакета; возвращать основную версию посетителям не потребуется.
