# Поддерживаемые HTML-входы старого интерфейса

Сохранены 07.10.2026 перед заменой публичного корня на V2. `manifest.json` перечисляет 55 HTML-файлов и базовую revision; снимок также содержит текущие локальные изменения интерфейса, поэтому baseRevision не означает чистый committed release.

`html/` — источник шаблонов, а публичные `index.html`, `ru/**`, будущие `old/**` — выходы. Не копировать автоматически опубликованные HTML обратно сюда: после переключения корня это были бы страницы V2.

- Изменения native HTML старого интерфейса вносить в соответствующий `html/<путь>`. Для экранов, которыми владеет локализатор, редактировать английский вход; RU и совместимые aliases генерирует `scripts/generate-localized-pages.mjs`. Сохранённые RU-копии остаются историей native разметки; для генерируемых страниц актуальный RU рендер получает локализатор.
- RU/EN тексты и SEO-данные локализатора поддерживаются в `scripts/seo/pages.mjs`, его guide copy и существующих JS-словарях. `renderLocalizedPages()` формирует Map в памяти, без чтения публичных выходных HTML.
- Общие JS/CSS, контроллеры, API и ассеты остаются в существующих `src/`, `app.js`, `styles/`, `assets/` и каталогах страниц. Не создавать независимые копии бизнес-логики для V1/V2.
- `npm run generate:seo` обновляет нынешние публичные V1 HTML. `npm run build:v2` компилирует HTML, legal/editorial content и facade V2 из поддерживаемых входов. Схема адресов пока прежняя; генерация `/old/` относится к следующему этапу.
- Сборка всегда включает runtime из текущего `app.js`. `ASG_V2_PRESENTATION_ONLY=1` теперь завершает сборку ошибкой. `v2/runtime-source.json` и `v2/build-inputs.json` обновляет только генератор.
- Реестр 29 экранов находится в `v2/page-registry.js`; используется HTML-генератором и `v2/routes.js`. Поле `target` описывает будущие RU-root/EN адреса, а работающие ссылки сейчас остаются `/v2/{ru,en}/`. `legacy: null` означает отсутствие отдельного эквивалентного V1 экрана.
- `v1-source`, `v2-source`, тесты и исследования исключены из dist. Не публиковать эти каталоги вручную.

Проверки: `npm run check:v2`, `npm run check:seo`, `npm run ci`. Для независимого локального артефакта можно задать `ASG_DIST_OUTPUT_DIR=C:/Python/asgracing/tmp/<имя>`; тот же путь используют manifest/reference/smoke проверки. Это не меняет production.

**Шаги 2–3, 07.10.2026:** `npm run build:root-candidate` формирует независимый макет адресов `/`, `/en/`, `/old/`, `/old/en/` с `noindex`. `npm run build:root-release` формирует отдельный кандидат с новым SEO, sitemap, совместимыми HTML-переходами и без публичного `preview/`. Исходный сайт и обычная сборка остаются в прежней адресной схеме до согласованной публикации. Полное описание и ограничения — [отчёт](../design-research/V2_RELEASE_STEPS2_3_2026-10-07.md). `retired-preview-routes.json` хранит только адреса для карты HTTP-редиректов и не зависит от будущего удаления Preview.

`tests/deployment/check-v2-build.mjs` собирает V2 из источников без публичных HTML, затем заменяет публичные файлы неправильным содержимым и доказывает одинаковый результат; также проверяет все 58 RU/EN экраны и запрет неполной сборки.
