# Подложки гоночных трасс ASG Racing

## Правило построения

1. Берём SVG viewBox, точки контура и координаты отсечек для действующей конфигурации из assets/track-maps. У Nürburgring 24h и Nordschleife общая схема.
2. Выгружаем участок вокруг трассы один раз. Оставляем лес, открытые площади, воду, дороги, пешеходные дорожки, здания, трибуны и пит-лейн. Записываем SHA-256 выгрузки. Под картой указываем © OpenStreetMap contributors.
3. Вписываем геоданные в существующую систему координат трассы. Для GeoJSON проверяем преобразование по точкам исходного контура. Локальную геометрию Race Control совмещаем с линиями OSM highway=raceway и замеряем расстояния по полному кругу. P95 выше 45 м требует ручной приёмки. У многофункциональных автодромов отдельно сверяем повороты и используемый в ACC вариант.
4. Расширяем поле подложки по бокам и оставляем запас сверху и снизу. Ориентир для новых трасс — ширина 3,55 высоты SVG и высота 1,22 исходной. Контрольный пример Spa использует границы -1000 -100 3200 1100. Основной viewBox сохраняется, контур масштабируется пропорционально.
5. Используем палитру Spa. Лес и поля зелёные, вода голубая, второстепенные дороги и здания приглушённые. Контур тёмный со светлой кромкой. Географические подписи и пины скрыты. Секторы красные #e33e49, старт/финиш белый. Приблизительность отсечек отмечаем в подсказке.
6. Проверяем совмещение и полный блок до строки «Геометрия» на десктопе, в низком окне и на телефоне. Перед интеграцией отдельно проверяем пробные живые координаты ACC и размер отдельного SVG.

## Воспроизведение

Нужны Node.js и Python с NumPy и SciPy.

    python -B prototypes/circuit-basemaps/fetch-osm.py <каталог-выгрузок>
    python -B prototypes/circuit-basemaps/build.py <каталог-выгрузок> <каталог-прототипа> --reference <f1-circuits.geojson>

Для COTA, Silverstone, Paul Ricard и Suzuka дополнительную опору даёт закреплённый [набор географических контуров](https://raw.githubusercontent.com/bacinger/f1-circuits/8094e957b8d6aa8b9f4510c93968556cccd30e02/f1-circuits.geojson). Для региона, где ограниченный Overpass временно недоступен, можно вырезать нужную область из PBF командой ниже. Для неё дополнительно нужен пакет osmium.

    python -B prototypes/circuit-basemaps/extract-pbf.py <код-трассы> <регион.osm.pbf> <код-трассы.osm>

Откройте index.html из каталога прототипа. При смене трассы загружается её отдельный SVG. В alignment.json записаны происхождение геометрии, границы подложки и результат совмещения там, где он измерен. HTML предназначен для визуальной проверки подложек и отсечек.
